# Phase 1 Public Asset Redaction Manifest

These are **public derivatives**, not evidence masters. Original files must remain unchanged and private.

## Carbis / Aluminum Ladder
- EXIF/GPS metadata removed from all exported JPGs.
- Close-readable labels/screens were blurred on selected images.
- Public set favors wide infrastructure views over serial-number closeups.

## Moore County Schools
- Original school floor plans are NOT public assets.
- Public derivatives intentionally obscure facility geometry, rooms, labels, names, and other usable layout details.
- Colored planning annotations are retained only to demonstrate discovery / solution-mapping methodology.
- No proposal pricing, staff/customer contact data, signatures, asset IDs, credentials, or infrastructure addressing should be published.

## Publication rule
Never substitute an original source file for a derivative with the same subject.
