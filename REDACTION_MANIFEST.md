# Phase 1 Public Asset Redaction Manifest

These are **public derivatives**, not evidence masters. Original files remain unchanged and private.

## Carbis / Aluminum Ladder
- EXIF/GPS metadata removed from all exported JPGs.
- Close-readable labels/screens are obscured where necessary.
- Public selections favor wide infrastructure views over serial-number or asset-tag closeups.
- No internal IP addresses, hostnames, credentials, MAC addresses, serial numbers, UUIDs, account information, or private configuration exports are published.

## Moore County Schools
- Original school floor plans are **not** public assets.
- Public derivatives intentionally destroy usable facility geometry, room labels, names, and other identifying layout detail.
- Planning-marker positions are retained only to demonstrate the discovery / solution-mapping methodology.
- Marker labels from the source artifacts are not retained.
- No proposal pricing, commercial terms, staff/customer contact data, signatures, asset IDs, credentials, or infrastructure addressing are published.

## Publication rule
Never substitute an original evidence file for a public derivative with the same subject.
